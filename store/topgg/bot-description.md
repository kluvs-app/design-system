Kluvs runs your book club inside Discord. Set up a club in a channel, pick the book, set a due date and schedule the discussions. The bot keeps track of the current read and who's reading along, so nobody has to scroll back to find it.

<hr style="border: 1px solid rgba(128, 128, 128, 0.2); margin: 24px 0;">

<p style="margin: 0; font-size: 11px; font-weight: 600; letter-spacing: 0.14em; text-transform: uppercase; color: #D16D30;">Get started</p>

## Up and running in four commands

1. Invite Kluvs to your server.
2. Run `/setup` in your club's channel. It registers the server and creates the club, and you become its owner.
3. Run `/session_create`. Search for the book, pick it from the list and set a due date.
4. Ask your readers to run `/join` in the same channel.

Already made your club on the Kluvs dashboard or in the app? Run `/link_club` in the channel you want and it picks up where you left off.

<hr style="border: 1px solid rgba(128, 128, 128, 0.2); margin: 24px 0;">

<p style="margin: 0; font-size: 11px; font-weight: 600; letter-spacing: 0.14em; text-transform: uppercase; color: #D16D30;">What it does</p>

## Everything a reading group needs, and nothing it doesn't

**Reading sessions.** One book, one due date, one list of who's reading. Check in any time with `/session`, `/book` and `/due_date`. When the club finishes, `/session_finish` closes the session and credits every member who read along.

**Discussions.** Plan topics ahead with `/discussion_add`, then run `/discussion_sync` to turn them into Discord events. Everyone sees them in the server's event list, with reminders.

**Quick recaps.** Fell behind? `/book_summary` gives an AI-written summary of the current book.

**One server, many clubs.** Every channel can host its own independent club, with its own book, schedule and members. Run as many as your community needs without them crossing wires.

## You decide who runs what

Server owners and anyone with the Manage Server permission can create and manage every club on the server. Inside each club there are three roles, so you can hand a channel to the people who run it without giving them the keys to everything:

<span style="background-color: rgba(201, 144, 10, 0.15); color: #C9900A; padding: 2px 8px; border-radius: 4px; font-weight: 600;">Owner</span> creates the club and can do everything in it.

<span style="background-color: rgba(0, 103, 129, 0.15); color: #006781; padding: 2px 8px; border-radius: 4px; font-weight: 600;">Admin</span> runs sessions, discussions and members. Promote readers with `/member_role`.

<span style="background-color: rgba(128, 128, 128, 0.15); padding: 2px 8px; border-radius: 4px; font-weight: 600;">Member</span> reads along, joins discussions and checks in on the book.

## For readers

- `/join` and `/leave` to take part in the club in this channel, or step away
- `/session` for the full session, `/book` for the current book
- `/due_date` for when it needs to be finished
- `/discussions` for what's scheduled next
- `/book_summary` for a quick recap

## For admins

- `/setup`, `/club_update` and `/link_club` for the club itself
- `/session_create`, `/session_update` and `/session_finish` for the reading cycle
- `/discussion_add`, `/discussion_update`, `/discussion_delete` and `/discussion_sync` for meetings
- `/member_add`, `/member_remove` and `/member_role` for the roster
- `/admin_help` for the full reference

Not sure where to start? `/help` gives a quick tour, and `/usage` lists every command you can use.

## Your club, wherever you read

Kluvs started as this bot. It's now also an app for Android and iOS and a web dashboard, all built around the same clubs. Sessions and discussions you set up in Discord show up there, and the other way round, so members who'd rather not live in Discord can still keep up. Readers also get a shelf, a reading log and a profile that follows them from club to club.

Discord is optional: a club can live entirely in the app and the web, and add the bot whenever it likes.
