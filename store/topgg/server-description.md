## Kluvs, in a few words

Kluvs is a small, focused way to run a book club: pick the book, set a due date, schedule the discussions and see who's reading along. It lives in a Discord bot, a mobile app for Android and iOS, and a web dashboard, all built around the same clubs.

- Add [the Kluvs bot](https://top.gg/bot/1327360422294192199) to your server and run `/setup` in your club's channel.
- Prefer an app? Find Kluvs for Android and iOS at [kluvs.com](https://kluvs.com).
- Run `/help` in any server with the bot for a quick tour.
